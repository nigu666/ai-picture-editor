# AI 修图智能体 · 本机安装版 local-20261025

这是在自己电脑上运行的版本，包含最新“悬浮画布”页面。通过本机网址打开，不需要服务器、域名或网站部署。

## 准备与安装

1. 使用 x64 Windows 10/11，安装并打开 [Docker Desktop](https://docs.docker.com/desktop/setup/install/windows-install/)，启用 WSL 2、切换到 Linux 容器模式。Docker Desktop 本身不包含在安装包中。
2. 将整个安装 ZIP 解压到固定目录，例如 `D:\AI修图本机版`。不要在压缩包预览中直接运行。建议至少留出 15 GB 空间；同时运行开发版或处理大图时需要更多空间与内存。
3. 双击根目录的 **安装并启动.cmd**。首次会校验文件、导入四个镜像、生成随机服务密码、初始化独立数据库并检查服务。这个过程无需 Node.js、Python 或开发环境。
4. 按窗口中显示的地址打开页面，通常是 `http://127.0.0.1:17401/editor`。端口被占用时首次安装会另选端口，之后使用 **查看状态.cmd** 查看实际地址。
5. 在网页注册自己的账号。安装包不含原开发项目的登录账号、素材和历史记录，也没有统一默认账号。

基础安装、已有模型和本地编辑可离线运行。AI 规划、生图、扩图、换背景等需要另配密钥并联网。没有密钥时普通生图是明确标识的占位模式，不能当作真实 AI 生图。

## 配置百炼

运行 **配置AI密钥.cmd**，粘贴阿里云百炼北京地域的 API Key，输入不会回显。该入口会保存密钥、启用相关 AI Provider 并重新启动服务，不主动提交任何模型任务。后续在网页执行 AI 操作可能产生平台费用。

也可以在本机编辑 `deployment/local/.env` 的 `DASHSCOPE_API_KEY`。AI 功能开关为 `IMAGE_PROVIDER`、`BACKGROUND_PROVIDER`、`OUTPAINTING_PROVIDER`、`UPSCALING_PROVIDER`、`REGION_PROVIDER`；需要启用的项目设置为 `dashscope`。参考图生成默认关闭，需要时再将 `REFERENCE_GENERATION_ENABLED` 改为 `true`。保存后运行 **启动.cmd** 使环境配置生效。

模型沿用项目当前设置：规划与视觉分析 `qwen3.6-flash`，普通生图与背景生成 `wan2.6-t2i`，图像编辑 `wanx2.1-imageedit`。平台账号还需具备相应模型访问权限。安装检查不调用这些付费接口。

**请保留生成的 `.env`，不要上传或分享。** 它包含数据库密码、存储密码、持久登录签名及可选 API Key。已有数据时不要重生成服务密码或更换 `INSTALL_ID`。

## 日常使用

| 入口 | 用途 |
|---|---|
| 安装并启动.cmd | 首次校验并导入镜像；再次执行会保留已有配置 |
| 启动.cmd | 启动本机服务，或让已保存的配置生效 |
| 停止.cmd | 空闲时停止服务，保留所有命名数据卷 |
| 查看状态.cmd | 查看各服务状态和实际页面地址 |
| 配置AI密钥.cmd | 安全输入百炼密钥并启用 AI 功能 |

关闭浏览器不等于停止容器。停止入口发现排队或运行中的任务时会拒绝停止；请先在网页等待任务结束。

仅向本机回环地址开放页面、图片存储与 MinIO 控制台；数据库和 Redis 不开放宿主机端口。HTTP 本地访问使用 development 环境的 Cookie 设置。此配置未作为公网安全部署配置验收。

## 数据保存与迁移

数据在 Docker 命名卷中，名称以 `.env` 中安装编号对应的 `aie-local-<编号>` 开头：`pg_data` 保存用户与会话，`minio_data` 保存图片，`redis_data` 保存队列。移动安装文件夹并保留 `.env` 后，仍可连接这套数据卷。

解压另一份未安装的包会生成新的编号，拥有独立的空白数据库。它不会自动读取开发版的图片或账号。停止脚本不删除卷；不要使用 `down --volumes`、Docker 的删除卷或清理所有数据操作来停止项目。

镜像包不是个人数据备份。更换电脑需另行备份与恢复数据库、图片存储及 `.env`；本安装包不自动导入旧用户数据，也不声称已完成跨电脑数据迁移验收。

## 常见问题

- 提示 Docker 未完成：先打开 Docker Desktop，确认 Linux 引擎已就绪，再重试。
- 文件校验失败：保留已有 `.env`，重新解压可信的原安装包，勿混用不同版本文件。
- 启动超时：先看 Docker 是否内存不足、磁盘不足、端口冲突。容器与数据会保留，可重试启动。状态中 initialize 正常完成后是 exited，不是常驻服务。
- 下载图片或预览失败：本机存储地址必须与 `.env` 中端口一致；不要只修改浏览器地址或把它直接分享给其他电脑。
- AI 功能不可用：确认密钥地域、账号模型权限、功能开关与网络。基础健康检查通过不代表云端接口已验收。
- PowerShell 被组织策略阻止：请联系管理员按组织规则运行脚本。本包不更改系统执行策略；入口只为当前子进程指定脚本执行方式。

镜像导入使用 Docker 官方 [save](https://docs.docker.com/reference/cli/docker/image/save/) / [load](https://docs.docker.com/reference/cli/docker/image/load/)；编排依据 [Compose 服务依赖](https://docs.docker.com/compose/how-tos/startup-order/) 与 [变量配置](https://docs.docker.com/compose/how-tos/environment-variables/variable-interpolation/)。
