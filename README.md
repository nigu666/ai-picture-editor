# AI 修图智能体

中文 AI 修图工作台，提供轻玻璃悬浮画布、本地图片编辑、图层操作和按需启用的 AI 功能。

[下载本机安装包](https://github.com/nigu666/ai-picture-editor/releases/latest) · [安装说明](deployment/local/安装说明.md) · [MIT 许可证](LICENSE)

## 功能

- 素材上传、会话管理、编辑历史与 PNG/JPEG 导出。
- 裁剪、翻转、旋转、调色、文字与图层操作。
- 本地抠图、SAM 区域选择、OCR 和 LaMa 背景修复。
- 使用阿里云百炼进行规划、视觉分析、文生图及图像编辑。
- 多步计划先展示，再由用户确认执行；候选图片可预览后采用。

## 安装与使用

本机安装包适用于 **x64 Windows + Docker Desktop Linux 容器模式**，无需在宿主机安装 Python 或 Node.js。

1. 打开 Docker Desktop，解压 Releases 中的本机安装包。
2. 双击 **安装并启动.cmd**，等待镜像导入和服务检查完成。
3. 在浏览器打开窗口显示的地址，通常是 `http://127.0.0.1:17401/editor`，首次注册自己的账号。
4. 如需使用 AI，运行 **配置AI密钥.cmd**，填写阿里云百炼北京地域密钥。

本地编辑与已附模型可离线运行。未配置密钥时规划不可用，普通生图为占位模式；云端功能需要联网、模型权限并可能产生平台费用。安装入口不会主动发起付费模型任务。

只有源码时，先运行 **从源码构建.cmd**，联网构建镜像并准备固定模型，然后安装。详细配置和故障排查见 [安装说明](deployment/local/安装说明.md)。

## 结构与数据

```text
React / Konva 工作台
       │ 同源接口与事件流
FastAPI API ─── PostgreSQL（账号、会话、历史）
       │       MinIO（图片）
Redis 队列 ─── Worker（异步任务）
                   ├─ 本地模型
                   └─ 用户自己的百炼账号
```

首次安装生成独立配置和随机服务密码，数据保存在 Docker 命名卷中。正常停止保留数据。仓库与安装包不包含个人账号、素材、真实 API Key 或开发机器配置。

不要上传安装后生成的 `deployment/local/.env`，也不要把数据卷当成镜像的一部分。跨电脑迁移需另行备份数据库、图片与私有配置。
